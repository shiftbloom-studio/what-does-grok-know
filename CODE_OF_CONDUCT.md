# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, review code like a gardener, not a judge. Harassment, discrimination and personal attacks are not welcome in any project space.

Report unacceptable behaviour to **safety@shiftbloom.studio**. All reports are handled confidentially.
